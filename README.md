# Bluestock Mutual Fund Analytics

## Project Overview

An end-to-end mutual fund analytics project covering data ingestion,
cleaning, SQL analytics, EDA, performance analysis, risk analytics,
and Power BI visualization.

## Objectives

- Data ingestion
- Data cleaning
- SQLite data warehouse
- SQL analytics
- Exploratory data analysis
- Fund performance analysis
- Risk analytics
- Investor analytics
- Power BI dashboard

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- SciPy
- SQLAlchemy
- SQLite
- Power BI
- Git/GitHub
